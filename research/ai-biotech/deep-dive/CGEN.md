# Compugen (CGEN) 深度分析

## 结论
- **市场几乎没有给 rilvegostomig 定价**。企业价值约 $1.1 亿，只比净现金（约 $1.18 亿）略低；换句话说，股价基本等于现金，研发管线被当作零。
- **核心赌注是 AZ 的 rilvegostomig 至少拿下一个适应症**。但同类 TIGIT 药物的 Phase 3 已经全部失败，所以这是一张低概率、高赔率的彩票，下行空间有现金托底。
- **近期可交易节点**：2026-10-05 的 KOL 活动（小事件）；2027 Q1 前的 MAIA 中期 PFS（中等事件，但样本只有 60 例）。
- **定位**：适合小仓位的"现金托底 + 期权"式配置；不是需要等待临床确认后才重估的标的。

## 2. Rilvegostomig（AZ 的 PD-1×TIGIT 双抗，TIGIT 臂来自 Compugen 的 COM902）
**规模**：12–13 项 Phase 3，入组超过 9,000 人。AZ 将其列为非风险调整后峰值销售可能超过 $50 亿的新药（[AZ 2024 投资者日](https://www.astrazeneca.com/content/dam/az/Investor_Relations/events/ID/Oncology-presentation.pdf)）。

| 瘤种 | 试验 | 设计要点 |
|---|---|---|
| NSCLC | ARTEMIDE-Lung02（NCT06692738） | 鳞癌，联合化疗 vs K 药 + 化疗，n=880，主要完成约 2029-02 |
| | ARTEMIDE-Lung03（NCT06627647） | 非鳞癌，vs K 药 + 化疗，n≈878 |
| | ARTEMIDE-Lung04（NCT06868277） | PD-L1≥50%，单药 vs K 药，n=830，主要完成约 2030-01 |
| | TROPION-Lung10 / Lung12 | 与 Dato-DXd 联用 |
| 胆道癌 | Biliary01（NCT06109779）/ Biliary02（NCT07221253）/ DESTINY-BTC01 | 辅助治疗、一线、HER2+ |
| 胃癌 | Gastric01（NCT06764875）/ CLARITY-Gastric02 | HER2+ 联用 T-DXd；CLDN18.2 |
| 其他 | HCC01、DESTINY-Endometrial01、TROPION-Urothelial04 | 2026-08 首例入组 |

**已有疗效数据**
- ARTEMIDE-01（NSCLC）
  - PD-L1≥50%：ORR 61.8%，mPFS 10.2 个月
  - PD-L1 1–49%：ORR 29%
  - 参考：K 药单药在 PD-L1≥50% 人群的历史 ORR 约 40–45%，但这是单臂试验，没有直接对照
  - 来源：WCLC 2024
- GEMINI-Hepatobiliary（一线胆道癌）：mOS 16.8 个月，历史对照不到 13 个月（[ASCO 2026](https://ascopubs.org/doi/10.1200/JCO.2026.44.16_suppl.4105)）

**Compugen 能拿到的经济利益**（2025-12 修订协议后，[PR](https://www.prnewswire.com/news-releases/compugen-monetizes-portion-of-rilvegostomig-future-royalties-to-astrazeneca-for-up-to-90-million-302644468.html)）
- 已收 $6,500 万；BLA 受理时再收 $2,500 万。
- 保留"大部分"特许权使用费。原协议费率为分级、最高"中个位数"；出售后保留的具体比例**未披露**，本文估算有效费率约 3%。
- 剩余里程碑最高 $1.95 亿（已包含上面的 $2,500 万），各节点金额未拆分披露。

| GSK/iTeos belrestotug | 2025-05 终止 |

| AZ volrustomig（PD-1×CTLA-4，AZ 的另一款双抗） | eVOLVE-Lung02 于 2026-08-17 停止，对 AZ 的双抗策略是负面信号（[AZ](https://www.astrazeneca.com/media-centre/press-releases/2026/update-on-evolve-lung02-phase-iii-trial.html)） |

**Rilvegostomig 仍可能成功的理由**
- 双抗结构，可同时结合同一细胞上的 PD-1 和 TIGIT。
- 大量试验与 ADC 联用；在这些组合里它相当于 PD-1 骨架，即使 TIGIT 本身没有额外贡献，也可能获批。
- 胆道癌 OS 数据积极。

**成功概率估算（主观判断）**
- 肺癌化疗联用类试验：20–30%
- 至少获批一个适应症：35–45%

## 4. COM701（抗 PVRIG，Compugen 自有资产）
- **既往数据**
  - 铂耐药卵巢癌（三联方案）：ORR 20%（n=20）
  - MSS 结直肠癌：ORR 5%
  - 结论：信号偏弱
- **竞争格局**：GSK 已放弃自己的 PVRIG 药物，COM701 几乎是唯一在研的临床药物。独占是优势，但大药企退出本身也是信号。
- **MAIA-ovarian 试验（NCT06888921）**
  - 设计：铂敏感复发卵巢癌维持治疗，60 例，按 2:1 随机对照安慰剂。
  - 管理层的成功门槛：COM701 组 mPFS 至少 6 个月，对照组基准约 4 个月（原假设 5.5 个月，已下调）。
  - 中期数据：2027 Q1 前。
  - 性质：只能发现信号，不足以支持注册。

## 5. GS-0321（抗 IL-18BP，授权给 Gilead）
- 进展：Phase 1 剂量递增中，包括单药和联合 PD-1。
- 已收款：$9,000 万。
- 后续：最高 $7.58 亿里程碑，特许权使用费为个位数至低双位数；下一个节点的金额未披露。
